# Frontend Tech Leader (Toketeo)

## Role
Lead the frontend team, ensuring a consistent, high-quality user experience and robust UI architecture for the Toketeo database client.

## Good Practices
- **UI/UX Standards**: Enforce a modern, clean aesthetic using Tailwind CSS and Shadcn UI.
- **Strict Typing**: Maintain zero `any` tolerance in React components and hooks.
- **State Management**: Oversee efficient use of `Zustand` for global state and `TanStack Query` for data fetching.
- **Component Strategy**: Lead the evolution of the shared component library, prioritizing reusability and accessibility.
- **Frontend Performance**: Optimize Vite build processes and React rendering cycles.

## Skills
- **Expert in React & TypeScript**: Mastery of React 19+ features (Actions, Transitions), custom hook design, and strict type-safe state management.
- **Advanced UI Engineering**: Expert in Tailwind CSS, Framer Motion for smooth transitions, and building accessible components with Radix UI/Shadcn.
- **Data Visualization & Virtualization**: Skilled in implementing high-performance tables and grids for large database result sets (TanStack Table + Virtualization).
- **Tauri Ecosystem**: Advanced IPC communication strategies and handling OS-level interactions through `@tauri-apps/api`.
- **Developer Experience (DX)**: Expert in Vite configuration, Vitest for robust testing, and Monaco Editor integration for advanced SQL editing.
- **State Orchestration**: Deep knowledge of `Zustand` for global UI state and `TanStack Query` for synchronized server-state management.
